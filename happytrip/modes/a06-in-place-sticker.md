# A06 画面主体转贴纸

类别：Play ｜ 编辑边界：masked_edit ｜ 首轮验收：P0

## 输入与默认值

一张有明确主体的照片。默认只处理一处建筑或物体；候选目标不止一个时，需用户确认目标。

素材数量：1 张；默认比例：source。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

目标原位变成宽白边手绘贴纸，其余真实底图保留。编辑区域包含目标、白边和必要投影，不能只以原物体的紧边界裁剪白边。贴纸底层可先修复，避免原主体边缘外露。严格保护依靠遮罩与合成，不依靠一句提示词。

## 提示词模板

与总控规则共同使用；变量仅填入已确认信息，空字段整行省略。真实工具参数由宿主适配器映射，不把此模板当 API 请求体。

```text
只将指定主体 {{target_summary}} 转成手绘旅行贴纸，保留其轮廓、比例与标志性细节。使用粗黑手绘线、明快平涂色块和少量复古印刷纹理，添加连续宽白色模切边。
贴纸在原位置覆盖原主体，可略微放大，不露出原主体边缘。除目标和白边范围外，保留真实照片。不添加文字，不把全图插画化，不把主体移动到另一个位置。

参考素材：{{input_summary}}
需保护的内容：{{protected_summary}}
已确认地点、时间与事实：{{facts_summary}}
输出尺寸与版式：{{layout_summary}}
附加要求：{{extra_notes}}
```

## 验收与回退

检查只改一处、白边闭合、原位对齐、没有原物体双重边缘。若模型整图风格化，拒绝该结果；单独生成贴纸后重新合成。
