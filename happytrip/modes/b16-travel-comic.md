# B16 旅行三格／四格漫画

类别：Story ｜ 编辑边界：reimagine ｜ 首轮验收：P1

## 输入与默认值

1–4 张人物与旅行照片，提供一句经历即可。默认四格，可选三格。格数不等于照片数，人物参考与景观参考应分别绑定。

素材数量：1–4 张；默认比例：3:4。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

有真实经历时先整理成格，再锁定角色外观和场景；没有经历时只提出想象剧情并标明，不能把自行创作的“迷路”“约会”等当作真实事实。逐格生成可更好复用角色参考；文字气泡和格线由排版器合成。

与总控规则共同使用；变量仅填入已确认信息，空字段整行省略。真实工具参数由宿主适配器映射，不把此模板当 API 请求体。

## 验收与回退

逐格检查角色一致性、格数、叙事顺序、对白拼写与事实来源。单格失误仅重做该格；用户未确认的情节应列为创作，不自动写成真实旅行日记。
