# B14 人像双重曝光旅行海报

类别：Story ｜ 编辑边界：reimagine ｜ 首轮验收：P1

## 输入与默认值

一张人物旅照即可提取人物和已有背景，或分别提供人物与景点两张参考。只有普通自拍且无景观时，应补充景观素材或确认使用想象场景。

素材数量：1–2 张；默认比例：3:4。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

人物轮廓为视觉主体，内部融合已确认景观，轮廓外保持克制留白。侧脸、背影或半身为构图选项；背影模式不强制“准确五官”，避免自相矛盾。未提供景观时不能自动制造貌似真实的旅途。

## 提示词模板

与总控规则共同使用；变量仅填入已确认信息，空字段整行省略。真实工具参数由宿主适配器映射，不把此模板当 API 请求体。

```text

轮廓边缘清晰，内部景观层次自然，色调统一，避免把照片简单半透明叠放。保留人物可见特征以及景观辨识度，外部背景简洁，预留标题空间。
```

## 验收与回退

检查轮廓清楚、景物来源正确、融合自然、没有第三张陌生面孔。缺景观先补素材或明确转为想象创作；不得宣称凭地点名称重现了用户的真实照片。
