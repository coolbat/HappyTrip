# B01 原片＋冰箱贴对照海报

类别：Collect ｜ 编辑边界：hybrid_layout ｜ 首轮验收：P0

## 输入与默认值

一张旅行原片。用户可指定提炼的人物、地标或物件。默认上部为纪念物展示，下部完整置入原片；比例为产品预设，可调整。

素材数量：1 张；默认比例：3:4。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

这是必须拆分的工作流：只让生成模型制作冰箱贴资产，再通过合成器放入未经生成式重绘的原片。原片默认等比完整显示，不裁主体；大小适配允许像素重采样，应表述为内容未重绘而非字节不变。严格原尺寸要求需使用原尺寸照片区域。

## 提示词模板

与总控规则共同使用；变量仅填入已确认信息，空字段整行省略。真实工具参数由宿主适配器映射，不把此模板当 API 请求体。

```text
从参考旅照提炼一个最有代表性的旅行纪念物：{{target_summary}}。制作精致的立体冰箱贴，保留该元素辨识度，具有真实边缘厚度与柔和投影。
这一阶段只生成冰箱贴资产或上方展示区域，不生成海报下方的原照片，不重绘原照片。风格与材质：{{mode_options_summary}}。
最终由排版程序把冰箱贴与原片组合，背景从原片提取颜色，版式干净克制，突出“旅行瞬间变成纪念物”。

参考素材：{{input_summary}}
需保护的内容：{{protected_summary}}
已确认地点、时间与事实：{{facts_summary}}
输出尺寸与版式：{{layout_summary}}
附加要求：{{extra_notes}}
```

## 验收与回退

检查上下同时出现纪念物与原片，原片来自原始资产而非模型输出；记录输入与复用资产哈希。缺少合成器时状态为 needs_capability，只能交付提示词与排版说明，不能称严格保真成图已完成。
