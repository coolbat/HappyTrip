# A12 ins 风画面注释

类别：Play ｜ 编辑边界：overlay ｜ 首轮验收：P0

## 输入与默认值

一张照片；标题与一句配文可选。没有文案时可给简短中性创作句，但不能编造旅行日期、同行关系或经历。

素材数量：1 张；默认比例：source。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

只增加文字和涂鸦层，底图不重绘。先确认保护区和可用留白，再排版；使用准确文字渲染，装饰以白色为主、少量点缀。无合成工具时不能保证底图像素不变；对严格保真需求，不应直接用整图重绘替代。

## 提示词模板

与总控规则共同使用；变量仅填入已确认信息，空字段整行省略。真实工具参数由宿主适配器映射，不把此模板当 API 请求体。

```text
为参考照片添加轻松、清爽的手绘注释层。保留原片内容、构图与摄影质感，在留白区域安排短标题、简短句子和少量箭头、星星、闪光、弧线。
白色为主，线条圆润而略不规则，文字与小图案疏朗穿插，避免堆满。避开脸、食物和关键地标，不把照片转成插画。
仅使用以下准确文案：{{text_summary}}。若采用分层流程，只生成装饰层，不重画底图。

参考素材：{{input_summary}}
需保护的内容：{{protected_summary}}
已确认地点、时间与事实：{{facts_summary}}
输出尺寸与版式：{{layout_summary}}
附加要求：{{extra_notes}}
```

## 验收与回退

检查文字准确、脸与关键主体无遮挡、留白充足。分别导出原底图与注释层的制作记录；最终合成图的注释覆盖区发生变化是预期行为。
