# B04 旅行玻璃球／雪景球

类别：Collect ｜ 编辑边界：reimagine ｜ 首轮验收：P1

## 输入与默认值

一张人物或景点照，可再补一张景观参考。默认透明旅行玻璃球；雪景、亮片和漂浮颗粒为可选项，不因名字含雪景球就给海岛加雪。

素材数量：1–2 张；默认比例：1:1。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

把核心人物与场景微缩放入玻璃球，保持玻璃外壳、稳定底座、折射与接触关系。内部元素不挤满，玻璃高光避开主要人物和地标。底座文字独立排版。

## 验收与回退

检查球体闭合、底座稳定、主体可见、季节未被擅改。人像过小或地标被遮挡时减少内部元素，而不是强化高光。
