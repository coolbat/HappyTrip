# A08 人物旅游海报

类别：Story ｜ 编辑边界：reimagine ｜ 首轮验收：P0

## 输入与默认值

至少一张人物参考照，另可附景点、美食或宠物素材。只有自拍时需要用户提供目的地，输出主题创作海报，不把画面当作实拍证据。

素材数量：1–8 张；默认比例：3:4。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

人物主视觉与城市元素构成复古拼贴。使用已提供或已核实的地标，未核实时不编造具体建筑名称与票据信息。宠物公路旅行作为此模式变体：需本人和宠物参考图，采用原创公路海报构图，不默认复制原文电影封面。

与总控规则共同使用；变量仅填入已确认信息，空字段整行省略。真实工具参数由宿主适配器映射，不把此模板当 API 请求体。

```text

围绕已确认目的地与素材，安排地标、街景、美食和装饰性票据、邮戳，采用撕纸边缘、印刷颗粒和克制手写元素。米白纸底搭配自然蓝绿与砖红，避免整体泛黄，人物肤色自然。
```

## 验收与回退

检查人物相貌、地标归属、视觉主次、肤色与文字。装饰票据不含真实身份证件号、假航班或未经确认的日程。宠物变体不得替换人物为不存在的陌生人。
