# A04 拍立得 3D 公仔打卡

类别：Story ｜ 编辑边界：reimagine ｜ 首轮验收：P1

## 输入与默认值

一张人物旅行照。需要可辨认的穿搭与场景；缺少下半身时，完整公仔的下半身属于创作补全，不声称精确复原原穿搭。

素材数量：1 张；默认比例：3:4。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

沿用原文约 1:4 的 Q 版人物比例与黏土质感，完整公仔置于手持拍立得中，部分肢体或道具突破边框。框内外景点应连续，背景不再复制一个主角。允许整图重构。

与总控规则共同使用；变量仅填入已确认信息，空字段整行省略。真实工具参数由宿主适配器映射，不把此模板当 API 请求体。

让一只手持握拍立得相纸，公仔立于照片内部并自然突破相纸边框，产生立体出框效果。拍立得内外延续同一景点，以统一的 Q版背景表达，不再出现第二个主角。保持手指、纸张透视与接触阴影合理，画面精致、留白适当。

## 验收与回退

检查公仔全身、真实破框关系、手指与相纸结构、框内外景点对应。未见服装细节不作真实性承诺。若人物被重复生成，优先删除多余角色，而不是改动主角。
