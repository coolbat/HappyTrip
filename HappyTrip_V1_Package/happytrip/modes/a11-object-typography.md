# A11 指定物体转文字涂鸦

类别：Play ｜ 编辑边界：masked_edit ｜ 首轮验收：P1

## 输入与默认值

一张照片，用户指定物体与对应词。可有多个物体，必须逐一建立目标、文字、颜色的绑定关系；不再复用 title 字段承载目标词。

素材数量：1 张；默认比例：source。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

字母笔画构成目标物体，不是把文字贴到物体表面。每个目标默认单色文字与少量辅助描线，字间保留镂空。目标被替换后镂空处需露出合理背景，隐藏背景的补全属于推断，不表示找回原本真实内容。

## 提示词模板

与总控规则共同使用；变量仅填入已确认信息，空字段整行省略。真实工具参数由宿主适配器映射，不把此模板当 API 请求体。

```text
只替换以下物体，并严格使用绑定文字与颜色：{{target_summary}}。
让文字本身构成物体的形态与轮廓。字母顺着结构排列，圆润粗笔画可拉伸、弯曲和嵌合，少量手绘描线补足空缺；文字仍尽量可读。每个物体按绑定的单色处理，字间透明镂空，不铺实色填块。
不能在原物体表面贴字，不能改成普通注释标签。其余照片保持真实。

参考素材：{{input_summary}}
需保护的内容：{{protected_summary}}
已确认地点、时间与事实：{{facts_summary}}
输出尺寸与版式：{{layout_summary}}
附加要求：{{extra_notes}}
```

## 验收与回退

先核对目标词拼写，再核对“文字构物”是否成立。残留实物、整块色填充或错误目标词均不合格。字形反复失败时，采用可编辑的字形路径合成方案，不能偷偷改为 A12。
