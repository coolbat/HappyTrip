# A10 美食炸弹

类别：Play ｜ 编辑边界：masked_edit ｜ 首轮验收：P1

## 输入与默认值

一张食物或饮品照片，可有人物手持。需要明确中心食物；对看不清的配料不自动猜测其具体种类。

素材数量：1 张；默认比例：source。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

允许编辑食物上方及飞溅经过的区域，不是只编辑容器内部。脸、手、完整容器及画面其他区域作为保护项；飞溅区必须绕开脸。仅使用原片可见或用户确认的原料。

## 提示词模板

与总控规则共同使用；变量仅填入已确认信息，空字段整行省略。真实工具参数由宿主适配器映射，不把此模板当 API 请求体。

```text
以指定食物或饮品 {{target_summary}} 为中心，制造超写实的腾空飞溅瞬间。固体自然散开，液体形成舒展弧面与细小液滴，原有配料悬浮，动势向上、向外并朝镜头展开。
保留容器完整与手持关系，不添加无关食材，不遮挡脸部。材质、透视、光线和阴影融入原片，像高速摄影定格，避免卡通与乱飞拼贴。
允许食材与飞溅强度：{{mode_options_summary}}。

参考素材：{{input_summary}}
需保护的内容：{{protected_summary}}
已确认地点、时间与事实：{{facts_summary}}
输出尺寸与版式：{{layout_summary}}
附加要求：{{extra_notes}}
```

## 验收与回退

检查容器未破裂、无无关食材、脸部不被遮挡、透视与光照一致。飞溅越界时缩小动势区域，不改变人物位置。
