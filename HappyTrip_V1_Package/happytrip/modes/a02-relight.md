# A02 自动调光

类别：Fix ｜ 编辑边界：global_adjust ｜ 首轮验收：P1

## 输入与默认值

一张照片。默认自然后期、轻度处理，不要求用户提供地点或日期。

素材数量：1 张；默认比例：source。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

默认只调整曝光、白平衡、色彩、对比与清晰感，不自动移除杂物、整理头发或改变天空。原文含指定位置的附加编辑，作为用户明确提出后的可选步骤保留；这是相较原文与前版模板的保守执行默认值。曝光调整会改变全图像素，因此验收“内容与几何不变”，不做全图像素相等判断。

## 提示词模板

与总控规则共同使用；变量仅填入已确认信息，空字段整行省略。真实工具参数由宿主适配器映射，不把此模板当 API 请求体。

```text
对参考旅照进行自然摄影后期：平衡曝光，控制高光，改善阴影层次、白平衡、色彩和清晰感。保留原始人物、物体、构图与透视，避免过饱和、光晕和塑料般肤色。
不要自行改变时间、天气或场景内容，不附带美颜或物体清除。原图已经丢失的细节不要宣称已真实恢复。
用户明确授权的额外局部调整：{{mode_options_summary}}。

参考素材：{{input_summary}}
需保护的内容：{{protected_summary}}
已确认地点、时间与事实：{{facts_summary}}
输出尺寸与版式：{{layout_summary}}
附加要求：{{extra_notes}}
```

## 验收与回退

检查无新增或删减物体、无几何位移，人物肤色自然，暗部和高光不过度处理。已经失去的细节保持自然，不强行“补出真实内容”。超出调光的请求先列入独立编辑任务。
