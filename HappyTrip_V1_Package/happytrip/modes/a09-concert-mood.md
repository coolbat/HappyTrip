# A09 演唱会氛围感照片

类别：Play ｜ 编辑边界：reimagine ｜ 首轮验收：P1

## 输入与默认值

一张现场人物照，可再附氛围参考图。不是自动修图模式；需用户明确选择氛围重构。默认不增加表演者身份、场馆名称或具体活动信息。

素材数量：1–2 张；默认比例：3:4。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

保留用户与现场主题，允许改变机位、姿态和光影。原文背对广角、前景应援棒和彩带是一种预设，不强制改变用户发型或性别表达。与“保持原现场纪实”冲突时，应改为 A02 或仅局部调色，不能同时承诺两种结果。

与总控规则共同使用；变量仅填入已确认信息，空字段整行省略。真实工具参数由宿主适配器映射，不把此模板当 API 请求体。

## 验收与回退

检查肢体协调、道具手持关系、光源方向与人物一致性。若用户锁定原构图，取消姿态与机位重构；不得为了氛围忽略用户保护项。
