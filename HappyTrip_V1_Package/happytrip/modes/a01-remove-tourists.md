# A01 消除背景游客

类别：Fix ｜ 编辑边界：masked_edit ｜ 首轮验收：P0

## 输入与默认值

一张旅照。必须能明确区分要保留的人与要移除的背景人物；多人合照有歧义时，先让用户指认或框选，不按站位自行认定同伴。

素材数量：1 张；默认比例：source。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

只编辑移除区域及必要的接缝过渡带。优先使用局部编辑，再把原图中未编辑区域合成回去。被遮挡的地面或建筑是推断性补全，不称为还原了真实隐藏细节。没有可用遮罩与合成工具时，明确只能尽量保留，不能承诺像素不变。

## 提示词模板

与总控规则共同使用；变量仅填入已确认信息，空字段整行省略。真实工具参数由宿主适配器映射，不把此模板当 API 请求体。

```text
清理这张旅行照片中明确指定的背景人物与杂物：{{target_summary}}。
保留指定主角、同行者、原始构图、镜头视角和已有光照。只在移除区域补全相邻背景，让建筑线条、地面纹理和阴影连续。不要误删同伴，不新增人物，不美颜，不改变天气，不把地点重画成另一处。避免重复纹理、漂浮物、残留肢体和涂抹感。

参考素材：{{input_summary}}
需保护的内容：{{protected_summary}}
已确认地点、时间与事实：{{facts_summary}}
输出尺寸与版式：{{layout_summary}}
附加要求：{{extra_notes}}
```

## 验收与回退

检查所有受保护人物仍在、目标已清除、建筑透视连续。目标含糊则进入 needs_input；接缝失败仅修复该区域。用户要求严格原图保护而缺少合成能力时，停止生成并说明所缺能力。
