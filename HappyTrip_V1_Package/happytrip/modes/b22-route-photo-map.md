# B22 路线照片地图

类别：Collect ｜ 编辑边界：hybrid_layout ｜ 首轮验收：P0

## 输入与默认值

2–15 张旅照及照片对应地点。连接为路线前需要用户确认站点顺序；照片上传顺序、文件时间与模型推断都不默认代表旅行顺序。

素材数量：2–15 张；默认比例：3:4。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

默认 itinerary_schematic：已确认站点按顺序组成概念路线，显著标注“行程示意，非比例地图”。未知顺序只输出不连线的地点集，或追问顺序。真实地理版需有来源的坐标与地理渲染器；城市间直线只表示站点关联，不表示实际道路轨迹。原片卡片采用确定性排版。

## 提示词模板

与总控规则共同使用；变量仅填入已确认信息，空字段整行省略。真实工具参数由宿主适配器映射，不把此模板当 API 请求体。

```text

站点、顺序与映射：{{mode_options_summary}}。默认以概念行程线表达，加入“行程示意，非比例地图”标识，不生成貌似精确的海岸线、街道、距离或坐标。
```

## 验收与回退

逐项核对照片归属、站点顺序、标签和示意说明。真实地理版还需核对坐标来源与地图署名要求。没有精确来源不生成公里数；没有真实轨迹不宣称绘制了实际行驶路线。
