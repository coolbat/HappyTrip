# A03 专业美颜

类别：Fix ｜ 编辑边界：masked_edit ｜ 首轮验收：P1

## 输入与默认值

一张有人物的照片；多人画面需明确修饰对象。默认保留身份特征、脸型、肤色特征与自然皮肤纹理。

素材数量：1 张；默认比例：source。数量为工作流设计边界，不代表任何服务商单次调用上限。

## 执行与边界

限定于用户同意的肤色均匀、临时痘印、眼下和发丝整理。妆容为显式选项，不默认增大眼睛、瘦脸、改变年龄或身体比例。原文作者提到脸型观感变化，本设计不将这种变化作为默认目标。对儿童默认仅做自然曝光与临时污点整理，不添加成人妆容。

## 提示词模板

与总控规则共同使用；变量仅填入已确认信息，空字段整行省略。真实工具参数由宿主适配器映射，不把此模板当 API 请求体。

```text
对指定人物做自然、克制的旅行照片修饰：{{target_summary}}。
改善轻微肤色不均、眼下疲态和用户指定的临时瑕疵，保留毛孔、自然表情、原本脸型与五官比例。保留具有辨识度的痣、雀斑及其他特征，除非用户明确要求移除。
仅在明确授权时整理发型或增加淡妆：{{mode_options_summary}}。不要整容式改脸、统一“网红脸”、过度磨皮或改变身体。

参考素材：{{input_summary}}
需保护的内容：{{protected_summary}}
已确认地点、时间与事实：{{facts_summary}}
输出尺寸与版式：{{layout_summary}}
附加要求：{{extra_notes}}
```

## 验收与回退

用户本人核对辨识度；检查脸型、五官位置、肤色与背景。不要以自动人脸相似分数替代用户判断。修饰过重则降低强度，不覆盖原图。
