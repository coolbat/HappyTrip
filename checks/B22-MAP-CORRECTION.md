# B22 真实地图交付修正

日期：2026-10-02；版本：1.1.1。

用户指出上次展示的图片没有地图。此前的风景原片预览仅是无底图的行程示意，未满足参考图中的真实街道地图效果；该反馈成立。

## 修正结果

- 地理海报默认 `map_layout: full_map`：下部全宽真实地图、原片浮动地点卡、准确位置锚点和引线。可显式选 `split`；超过 4 个照片地点绑定时保留全部照片并记录回退原因。
- 浮动卡不遮挡定位点；无地理底图的示意模式不能使用 `full_map`。
- Skill 入口、模式指南和参考文档明确要求：用户要真实地图时，成图必须包含清楚可见的地理底图，不能用无底图的示意图代替。
- Planner 保留 `map_layout`；合成 manifest 记录请求布局、实际布局与回退原因。

## 新预览与素材

[完整地图海报](../docs/examples/b22-map-preview.png) 使用真实旧金山底图及三张公开授权地标照片，明确标为效果示例，非个人旅行记录。照片未进行生成式重绘。红色虚线仅表示站点关联，未声称道路路径或旅行里程。

地图来自 [USGS The National Map / USGSTopo](https://basemap.nationalmap.gov/arcgis/rest/services/USGSTopo/MapServer)，按服务返回的实际 Web Mercator 范围配准；底图来源与署名保留在配方及成图。照片来源、作者、许可与原始链接见 [素材署名](../docs/examples/CREDITS.md)。原始哈希清单保留在本地 `outputs/b22-map-correction/photos/sources.json`。仓库仅附带成图及署名；地图和照片不放入 Skill 安装包。
