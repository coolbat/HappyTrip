# HappyTrip 案例展示

这里记录仓库首页使用的实际图片与制作方式。素材均为公开授权地标照片，不代表用户的旅行经历。完整照片作者、许可与地图来源见 [CREDITS.md](CREDITS.md)。

| 场景 | 模式 | 展示方式 |
| --- | --- | --- |
| 去掉景点游客 | A01 | 卢浮宫广场清理前后对照 |
| 优化光影与色彩 | A02 | 金门大桥 AI 自然调光前后对照 |
| 制作旅行冰箱贴 | B01 | 立体纪念物与完整原片合成海报 |
| 制作水彩明信片 | A05 | 原片与水彩创作对照 |
| 制作旅行玻璃球 | B04 | 原片与微缩纪念物对照 |
| 整理照片与地点 | B22 | 真实地图、原片卡与地点标记 |

更多人像修整、照片注释、旅行合集、漫画、美食特效和人物海报，见 [12 类常见场景与提示词](../common-scenarios.md)。后六类提供使用配方，尚未在本页添加实图。

## A01 · 去除背景游客

[公开原片](louvre-source.jpg) → [查看清理后照片](a01-cleanup.png)

输入为 Guilhem Vellut 的卢浮宫广场照片（CC BY 2.0）。内置 `image_gen` 生成去除游客的候选，再通过本项目的遮罩合成器，只将下方游客所在区域合入原片。骑马雕像属于建筑艺术品，予以保留。

原图为 1600×1067。顶部 704 行保留原片；第 704–721 行渐变过渡，下方使用生成区域。合成器确认有效遮罩外改变的像素数为 0。被人遮挡的铺地、栏杆和阴影属于推断性重建，不能当作现场细节记录。[有效遮罩](a01-cleanup-effective-mask.png) · [合成检查](composition-records.json)。

## A02 · 自然调光

[公开原片](golden-gate-source.jpg) → [查看光色优化照片](a02-natural-light.png)

输入为 Wattewyl 的金门大桥照片（CC BY 3.0）。内置 `image_gen` 提亮前景山坡和右侧暗部，调整白平衡与色彩层次。视觉复核未见新增云朵或明显新增物体，桥塔、海湾、城市和前景的整体构图保持一致。

**这是 AI 编辑示例，细小纹理可能重绘，不是逐像素无损调色。** 树叶、海面和远处建筑仍可见细节重新解释，严格要求几何和纹理不变的工作不能以本例作为已通过验收的证据。

## B01 · 原片＋冰箱贴

[公开原片](golden-gate-source.jpg) → [查看完整冰箱贴海报](b01-magnet-poster.png)

先用内置 `image_gen` 将金门大桥提炼为透明背景的树脂／陶瓷浮雕纪念物，再由本项目 B01 合成器制作 1200×1600 对照海报。标题通过独立文字层排版，下方复用已登记原照片，等比完整显示；没有让生图工具重画对照原片。

原片经过尺寸适配重采样，但没有裁切或语义编辑。来源检查通过；纪念物边缘厚度、投影和原片完整性已看图复核。输出是创意图片，不是实体商品或生产图纸。[合成检查](composition-records.json)。

## A05 · 水彩明信片，无字版

[公开原片](golden-gate-source.jpg) → [查看完整明信片](a05-watercolor-postcard.png)

输入为 Wattewyl 的金门大桥照片（CC BY 3.0）。使用内置 `image_gen`，按 A05 模式卡转绘为横版水彩明信片：右侧景物、左侧留白与三枚色块。此案例选择无字版，未添加地点题字、日期或私人故事。

## B04 · 旅行玻璃球

[公开原片](pier39-source.jpg) → [查看完整玻璃球](b04-travel-globe.png)

输入为 Daderot 的 39 号码头照片（CC0）。使用内置 `image_gen` 将木栈道、临水建筑和海湾重构为玻璃球内的微缩景物。未添加雪景或文字；输出是创意纪念物，不是实体商品照片。

## B22 · 真实地图海报

[查看完整地图海报](b22-map-preview.png)

使用 USGS 的真实地理底图，确定性排版金门大桥、39 号码头、渡轮大楼三张公开照片。照片卡复用原片；红色虚线表示站点关联，不表示实际道路、导航轨迹或旅行里程。[实现与复核记录](../../checks/B22-MAP-CORRECTION.md)。

## 制作与复核

六个案例中，A01／A02／B01／A05／B04 使用内置生图工具，A01／B01 另经本项目合成器完成；B22 使用已有真实地图排版结果。[完整生成提示词](generation-prompts.json)、[合成记录](composition-records.json) 与 [图片来源、哈希和复核记录](showcase-record.json) 保留在仓库。

累计两轮使用 7 次生图调用：5 个生成结果用于上述案例，2 个 A02 候选未采用。一个为金门大桥增加了天空纹理，另一个抹平了码头远处人物细节；未采用图片只保留在本地。最终 A02 以明确标注限制的 AI 调光参考展示，不宣称严格保真验收通过。

这些单例不等于全部 18 种模式的实图矩阵验收，也不代表用户审美认可。源文件哈希与输出尺寸可核对；原始候选和工作中间文件保留在本地，仓库收录用于展示的结果、有效遮罩及来源记录。
